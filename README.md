# SnapCode

Beautiful code screenshot generator built with Next.js, React, and Tailwind CSS.

## Features

- Multiple syntax themes (Dracula, Monokai, GitHub Dark, One Dark)
- Gradient and solid background options
- Adjustable padding, font size, and border radius
- Line number toggle
- Custom file title
- SVG export
- 30+ language support
- Real-time preview

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Tech Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS

## 🇫🇷 Documentation en français

### Description
**SnapCode** est un générateur de captures d'écran de code magnifiques, construit avec Next.js, React et Tailwind CSS. Collez votre code, choisissez un thème et un langage, puis exportez une image prête à partager sur les réseaux sociaux ou dans vos présentations.

### Installation
```bash
npm install
npm run dev
```

### Utilisation
Ouvrez [http://localhost:3000](http://localhost:3000), collez votre code dans l'éditeur, personnalisez le thème et le fond, puis téléchargez l'image générée.
