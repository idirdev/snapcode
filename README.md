# SnapCode

Beautiful code screenshot generator built with Next.js, React, and Tailwind CSS.

## Features

- Multiple syntax themes (Dracula, Monokai, GitHub Dark, One Dark)
- Gradient and solid background options
- Adjustable padding, font size, and border radius
- Line number toggle
- Custom file title
- SVG export
- 30+ language support
- Real-time preview

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Tech Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
